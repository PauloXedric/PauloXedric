### 📌Featured Project

#### Coraoke — Real-Time Karaoke Room App
  > A real-time karaoke web app where users create or join rooms, queue songs, and sync everything live across all participants.

  🔗 [Live Demo](https://coraoke.corfish.com)

  - Public and password-protected karaoke rooms with host session control
  - Real-time queue sync across all participants via **SignalR**
  - Separate **Identity** and **AppData** microservices, JWT via query string for WebSocket auth
  - Theater/fullscreen mode with Netflix-style queue overlay
  - Rate-limited auth with forgot/reset password flow

  **Stack:** Angular 20 · ASP.NET Core 9 · SignalR · EF Core · JWT · ASP.NET Core Identity

  > A full-stack platform for building and managing professional portfolios — skills, experience, projects, certifications, and more.

  🔗 [Live Demo](https://corpxolo.corfish.com)

  - Dynamic portfolio sections: experience, skills, projects, certifications, languages, references
  - Public portfolio view with clean profile presentation
  - File upload support and profile management
  - CQRS architecture with clean separation of Identity and AppData services
